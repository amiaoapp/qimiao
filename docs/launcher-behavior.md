# 启动器交互说明

- 默认网格窗口为 920×600；列表为 680×600 的可滚动单列，切回图标模式恢复网格尺寸。窗口尺寸会适配当前显示器。
- 搜索会查询整个应用列表，包括应用原名、扫描时的搜索词、中文系统名称、拼音和首字母。比如“终端 / zhongduan / zd”匹配 Terminal，“活动 / 内存”匹配 Activity Monitor。
- 分类管理中的“一键智能分类”使用本地名称、路径末段及平台类别信息匹配用户已有分类。不会向外部服务上传应用列表，不覆盖已有有效分类，不确定的项目留作手动分类。
- 跟随系统、浅色、深色主题分别使用显示器、太阳、月亮图标。系统外观变化会更新网页和 macOS 原生玻璃的明暗状态。
- 在应用首页或命令模式输入“关机、重启、待机、睡眠、熄屏、锁屏”等可出现系统指令候选。关机、重启、注销、睡眠和清空废纸篓等操作先显示确认框。
- Windows 和 Linux 另提供休眠候选；macOS 只提供系统公开的睡眠和显示器睡眠，不会更改全局休眠策略。Windows 熄屏与睡眠使用不同的系统操作。操作失败时显示系统返回的错误。
- Windows 图标按 Shell 返回位图的实际尺寸读取，再去除透明阴影和白底留白，按统一可见尺寸排入相同的圆角底板；旧缓存自动失效。找不到图标时显示占位，不无限转圈。图标本身内嵌的复杂底色不做破坏性抠图。
- Windows 添加应用统一在一个窗口中操作：选择当前/公共桌面、开始菜单或指定文件夹后批量勾选，也能直接多选 `.exe` / `.lnk`。读取候选只在点击来源时发生，不恢复后台自动抓取；已添加项不能重复勾选。目录最多读取 2000 项，筛选列表显示前 200 项。
- 点击应用先隐藏启动台，再让系统打开应用，不显示等待中的提示；启动失败时恢复启动台并显示错误。

系统关机、重启、睡眠等指令的回归检查只验证候选、确认流程和代码编译，不在开发者电脑上实际触发电源操作。

## 外观、字体与窗口

- 银灰 / 石墨色材质使用同一套对比度、边框和圆角变量，不增加彩色光斑或跟随指针的模糊层。macOS 原生液态玻璃保留。
- 分类 / 翻页渐入、图标轻浮起与按下回弹、弹窗过渡只用透明度和位移。设置可关闭动效，也会遵循系统 `prefers-reduced-motion`。没有常驻逐帧循环。
- 设置 → 外观 → 界面字体，可以搜索、预览和选择本机字体。macOS 从 NSFontManager 读取字体家族，Windows 从 GDI 枚举，Linux 使用 fontconfig；不会扫描并上传字体文件，也不从远程下载字体。
- 字体选择即时生效并保存在配置中，备份只包含字体家族名。另一台电脑缺少该字体或字体缺少某些字形时，按系统字体栈回退。系统默认始终可选；安装新字体后可点击刷新字体列表。
- 浏览器预览只检测少量已知本地字体家族，完整字体目录以桌面程序为准。
- 字体弹窗按 Esc 只关闭字体弹窗，仍留在设置；主界面的 Esc 隐藏窗口不变。
- 顶部短横线与界面空白处可拖动窗口。搜索框、按钮、分类滚动、应用拖拽不触发窗口拖动。位置不持久化，下次唤起恢复水平居中、垂直剩余空间 58% 的位置；内部模式切换不重新定位。
- Windows 使用单层 6px 网页透明圆角，不再叠加 GDI 圆角区域与 DWM 圆角。原生边缘最终效果仍需 Windows 实机确认。
- 设置或顶部工具栏可切换简洁模式：窗口收为 680×430，仅保留搜索、最近使用与常用命令；搜索应用、计算或系统操作仍可用。上下键选择、回车执行，输入法组词期间不会执行；右上角展开按钮恢复完整网格。导入窗口打开时临时恢复完整尺寸以避免内容被截断。

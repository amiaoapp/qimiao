# 启喵

APP喵旗下的跨平台智能应用启动器，使用 Tauri 2、Rust、React 和 TypeScript 构建。

支持 macOS（Apple Silicon / Intel）、Windows 和 Linux。

## 功能

- 自动扫描并启动系统应用，支持收藏、分类、中文与拼音搜索
- Launchpad 式分页、列表模式、毛玻璃与液态玻璃主题
- 全局快捷键、菜单栏常驻、失焦自动隐藏
- 可用的计算器、剪贴板、快捷链接和 AI 翻译扩展
- OpenAI Compatible AI 查询
- 简体中文与英文界面

## Development

```bash
npm install
npm run tauri dev
```

## Build

```bash
npm run tauri build
```
